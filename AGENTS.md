# Frameweave repository

Read the [Agent authoring guide](docs/authoring/AGENTS.md) when creating or editing a project. New projects receive that guide through `frameweave init`.

Keep changes scoped to the engine or library involved. Preserve typed Stage inputs and outputs, deterministic frame and sample time, resource ownership, package integrity, and license notices. Verify the affected public CLI or SDK path and inspect actual media when changing rendered output. Keep generated media, local caches, installed dependencies, and platform binaries outside versioned source.
