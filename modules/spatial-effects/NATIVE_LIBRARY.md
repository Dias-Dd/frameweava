# Native library: 50 existing functions

Source entry: `native-library.ts`. Editable creation:
`examples/native-library/project.tsx` (640x360, 24 fps, exactly 1 second).
This batch admits **50 distinct existing algorithms** to the current Native
Scope; it does not advertise 50 newly invented algorithms or count aliases.
Their calculation source bytes are unchanged from ee95ea96.

| Group | Count | Named exports |
|---|---:|---|
| Spatial images | 15 | mandelbulb, mengerSponge, gyroidSurface, voronoiCrystal, terrainRaymarch, metaballVolume, planetAtmosphere, heightFog, volumetricSpotlight, smokePlume, flameVolume, waterCaustics, starfield, orbitalTrails, gravitationalLensing |
| Non-color spatial fields | 15 | deviceDepthToViewDepth, viewDepthToRayDistance, reconstructWorldPositions, projectWorldPositions, reconstructNormals, cameraMotionFromDepth, reprojectionVisibility, distanceToPointField, distanceToPlaneField, surfaceCurvatureField, surfaceGradientField, reflectionDirectionField, refractionDirectionField, reduceDepthBounds, surfaceTangentFrame |
| Mesh/Puppet geometry maps | 15 | transformPositions, twistPositions, bendPositions, taperPositions, shearPositions, stretchPositions, bulgePositions, spherifyPositions, cylindrifyPositions, wavePositions, ripplePositions, noiseDisplacePositions, morphPositions, cageDeformPositions, attractPositions |
| Spatial computation | 5 | cellularVolume, vortexField, curlNoiseField, splatParticles, renderVolume |

```ts
import {wavePositions,twistPositions} from './modules/spatial-effects/native-library.ts';
// Existing defineNativeStage factory. restPositions is a resident f32 XYZ field.
const wave = await wavePositions(init.gpu, restPositions, context, {
  amplitude: .15, frequency: 5, phase: context.time * 5
});
try {
  const result = await twistPositions(init.gpu, wave, context, {rate: .7});
  // Feed result directly to init.gpu.drawMesh / another map, then release it.
} finally { await init.gpu.releaseBuffer(wave); }
```

The example demonstrates chained deformation -> the **same** Native drawMesh
and compositor. `GpuPixelImage` and `GpuDataBuffer` remain Stage-local opaque
capabilities. Spatial fields retain their existing value + independent validity
pair, camera/time/space/units and missing-sample semantics. No new P4 port, Host,
registry, simulator, device or message bus exists here. Time and Signals use the
existing context. These five computation exports need no hidden history.

All effects use actual GPU execution. Initial authored numeric arrays are
explicit inputs, not CPU pixel fallbacks. The image functions retain scene-linear
Rec709/D65, PM/opaque input and PM F16/F32 output contracts. Non-color geometry
and fields remain f32 with explicit semantic/units. Other working colours and straight Alpha require explicit conversions. The
new Native convertColor can convert working colours before these legacy Rec709
operators; their existing input guards remain unchanged. No automatic SDR8, resolution, sample-count or geometry reduction.
Existing per-function work budgets and actual owner/device limits still apply.

Inputs and Scope are borrowed. Every returned image/data buffer is caller-owned;
release it explicitly or use the existing `withGpuResources` arena. For spatial
pairs release both data and validity (tangent/bitangent have independent masks).
The Stage disposes its immutable seeds; Core owns Scope/device and queue lifetime.
Logical release is not GPU completion. Compilation caches reuse the same Scope.

To read a result deliberately, publish it **inside** renderAt:

```ts
await init.gpu.publishBuffer('positions', result, {version: 1});
// Outside authored Stage logic, using the same public Renderer:
const ticket = await renderer.submitNativeFrame(frame);
await ticket.completed;
const cpu = await renderer.exportNativeBuffer(ticket, 'stage-id/positions');
```

Local publication names cannot contain `/`; the host adds the Stage prefix.
Publication alone does not read back. `readDeformedPositions` / `readSpatialField`
inside renderAt remain unsupported and are **not** exported by this Native entry.
Normal video has zero named-buffer readbacks; explicit verification intentionally
reads data. GPU -> packed output -> FFmpeg still materializes final video bytes.

## Actual verification and limits

`validation/native-library/evidence/` retains raw values, JSON, original failures,
timings, PNG/storyboards and the fully decoded 24-frame MP4. The final inventory
is machine-generated by `validation/native-library/finalize.ts`.

- 50 functions / 81 actual GPU cases. Spatial/mesh functions compare against
  existing independent F64 references, including holes, borders, odd dimensions,
  camera motion, Snell/TIR, planes/sphere, deformation extremes and noise.
  The five compute cases use F64/FastNoiseLite/Beer-Lambert references.
- All 15 image functions execute in F16/F32. Finite RGB, Alpha, coverage and
  repeat checks pass. Direct generators use one final Half-rounding bound;
  fog/lens chains also measure actual intermediate Half error and propagate it
  through transmittance/convex bilinear sampling. The original wrong one-rounding
  assertion and exact source snapshot are retained, not silently relaxed.
- Real readonly image views + public completed-ticket exports verify signed HDR,
  soft/zero Alpha and Alpha-zero emission. Raw RGBA and black/white composites
  match exactly for identities; constant fog max error is 1.1920929e-7.
- Same/new renderer geometry replay is exact. PNG initial/middle/final and public
  source CLI output match; all video frames decode. Raw/decoded storyboards and
  all 15 diagnostic image cards were visually inspected. H.264 is lossy; it is
  not included in lossless float assertions. PNG display conversion clips/maps
  HDR; it is not evidence that HDR values were clipped in the GPU calculation.
- Independent production binary copy matches all 12 frozen owner inputs and its
  executable SHA; no shared build cache, new Rust build or owner code edit.
- The first Surface control run exposed missing SpiderMonkey btoa/atob. Small
  byte-string intrinsics now live in its independent runtime, covered by byte,
  padding, invalid-input and chunk tests plus actual float Surface/GPU roundtrip.
  No DOM/Node/file/network capability or automatic WASM authorization was added.

Measured only on Windows / RTX 5070 Laptop / Vulkan / driver 596.49. Numerical
fixtures are small; image probes are 128x72 and the creative scene 640x360. This
does not qualify 4K, all hardware, invalid-GPU-content asynchronous diagnostics,
device-loss recovery, interactive scanout or full installed/exported distributions.
Wall timings include host/submit/complete/export, never GPU timestamp claims.

This is an editable Native **source** entry. R1/native package identity, catalog,
root SDK exports and portable/install acceptance remain Main integration work.
No old package/lock/trust identity was changed. Current Core still needs the
previously delivered SpiderMonkey reference wiring; tests explicitly use that
loader, not a hidden production patch. Ordinary explicit Web remains separate.

Remaining migration: old ARAP/mesher Worker+WASM execution is not made Native by
the new GPU buffer export. The second Main synchronization delivered UV/texture commands; old Puppet/atlas
adapters still need their own migration and qualification. The ten historical state-update compute functions
are not in this batch; using the new ordered GPU state API and deterministic
reset/replay is follow-on work, not implicit history added by these five exports.
WebGL capture/import is not a Native geometry AOV producer. Arbitrary external
objects, resources or GPU handles are never auto-imported.

Reuse: existing authored Apache-2.0 geometry/field/visual math; the fixed MIT
FastNoiseLite v1.1.1 subset at commit 7ccfbc16eb1c932568f177d63a9ba51d89bbe516
in the three existing vendor/SOURCE.json files. Three camera math uses the
already installed/pinned dependency. No new dependency, GPL source or third-party
binary is introduced. Base64 helpers are authored from the
[Infra algorithm](https://infra.spec.whatwg.org/#forgiving-base64) and
[HTML byte-string behavior](https://html.spec.whatwg.org/multipage/webappapis.html#atob);
only InvalidCharacterError.name is provided, not a full DOMException platform.
