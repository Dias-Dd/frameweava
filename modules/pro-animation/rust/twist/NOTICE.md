# PA3 Twist radial path adapter

The radial map, analytic Jacobian and endpoint/derivative-matched cubic controls reuse EffectCraft `crates/path/src/ops.rs`, commit861c51f8187bf56efc77cc7b60fc4a513d2b7198, MIT OR Apache-2.0. Original complete source and a selected unchanged function-body excerpt are preserved under `upstream/`. Original source SHA25698679efdf568338fe274c7cfc9719afe525c5ac07c6d5ad47cf06ebbdf6347ac. Original MIT/Apache notices are under `licenses/`.

The adapter normalizes coordinates around the explicit radius, uses a stable unit-vector dot product, and evaluates the exact zero-radius derivative limit rather than an arbitrary epsilon. The original map/Jacobian model remains unchanged. Default normalization uses the whole control hull, so loops whose endpoints coincide with the center are not incorrectly treated as identity; explicit radius preserves caller control. This is not an Adobe compatibility guarantee.

The original 64-subdivision clamp/heuristic is replaced by an original Frameweave analytic second-derivative error bound and iterative subdivision. For G=radial-warp(cubic)-cubic, the paired-parameter Hermite error in real arithmetic is at most M2/4. Curve control hulls bound radius, velocity and acceleration. Floating calculations reserve an explicit conservative ULP margin and fail below that floor; this is not a formally verified directed-rounding interval implementation. Endpoint chords may be used only when a whole radial enclosure bounds the error within the requested accuracy. Existing caller/Graphics resource limits and convergence errors remain explicit, without silent quality reduction.

Kurbo0.13.1 remains the existing unmodified MIT OR Apache-2.0 crate and reviewed Cargo tree. Its experimental approximate general curve fitter was inspected but not used here.
