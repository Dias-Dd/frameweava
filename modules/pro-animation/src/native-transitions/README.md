next immutable R1 version, public `pro-animation` exports and locks; these names
are **not claimed installed in pro-animation@0.7.3**. Existing text WIP is separate.
The baseline package has schema-1 **Web-only** bindings. Formal native imports
need Main's reviewed native binding/version; routing through that old Web
initializer would be incorrect. The current builder also enumerates only flat
source filenames and rewrites three-parent SDK imports. It must deliberately
carry this nested source graph, public SDK/native type references and licenses,
not merely add value declarations. No P4/ABI change is made by this checkpoint.

```ts
import {createNativeTransitions} from './index.ts';
// In the existing defineNativeStage factory:
const fx = createNativeTransitions(init);
// In renderAt(context), with SAME-owner resident inputs:
const wiped = await fx.directionalWipe(from, to, {
  progress: existingKeyframes, direction: [1, -1], softness: .08,

const final = await fx.crossDissolve(wiped, to, {progress: .1});
await init.gpu.release(wiped);

```

Every listed function is also a named export, with `gpu` as its first argument.
The binding factory removes only that argument. It creates no owner, scheduler,
queue, simulation, resource store or timeline. No runtime shader downloads.

## Shared contract

- Native-wgpu hardware-admitted Stage scope only; no browser-GPU/CPU fallback.
  Authored JS still runs inside the existing Chromium isolation boundary; all
  media pixels are generated by Rust/wgpu. Admission is not a precision certificate.
- Explicit **identical scene-linear color encoding**; sources share dimensions.
  Extended masks can differ in size and use explicit placement; Twister centers a
  differently sized backside without scaling. Owner tokens enforce ownership.
  RGBA16F/32F only; output defaults to source format and is premultiplied.
  Dimensions/format/color are inherited. No SDR intermediary, no RGB clamping.
- Straight inputs associate **before** bilinear interpolation. Native PM RGB at
  Alpha zero is retained; hidden straight RGB at Alpha zero contributes zero.
  Masks intentionally interpret PM Alpha-zero color as zero, a stated mask rule.
- `progress` is a number or existing numeric Signal in [0,1], evaluated once per
  call. Omitted progress requires `context`, using its local `progress`. Repeated
  calls and arbitrary requested times have no frame history. No global time rewrite.
- Exact progress 0/1 returns outgoing/incoming PM pixels through a real GPU pass.
  `softness` defaults .05 in normalized mask units, not Gaussian blur pixels.
  Color is straight linear RGBA, associated once. Feather/mask values may saturate;
  image RGB does not. Sampling uses integer pixel centers and explicit edge policy.
- Uniforms/phase/transcendentals use F32; crossfade uses existing compensated Pair
  arithmetic and progress hi/lo. The edge-on twist inverse additionally uses
  compensated coordinates, CPU-prepared scalar sin/cos coefficients and a bounded
  [0,pi] compensated Taylor cosine (no CPU pixels). F16 publishes RNE at **each logical pass**, through
  the existing owner. This is not exact F64 geometry or AE pixel equivalence.
  Existing native production deliberately does not scan every pixel for numerical
  errors: valid finite inputs and representable intermediates remain the caller's
  contract. Huge coordinates/trig phases, subnormal input arithmetic and overflow
  are not certified by this checkpoint. No claim of Web PixelScope validation here.
- Resources are frame-local. Caller releases outputs; do not retain image tokens
  across renderAt calls. Factory has nothing to dispose and never disposes its GPU.
  `await fn()` means **recorded**, not GPU complete. Await the Renderer frame ticket.
  Abort is checked before recording and after compile; it cannot preempt a shader.
  Owner failure/cleanup retain existing semantics; no hidden retry/CPU replay.
- Stable preflight errors: `E_PA_TRANSITION`, `E_PA_TRANSITION_DEVICE`, existing
  `E_RENDER_CANCELLED`; new blur profiles also use `E_PA_TRANSITION_GAUSSIAN_REQUIRED`
  and `E_PA_TRANSITION_BLUR_DOMAIN`. Owner/resource errors propagate unchanged.
  No new artistic resolution/path limits. Existing device/packet/memory bounds
  still apply; exact-integer cell/point phase is bounded by F32 representability.

## AE category comparison, not a coverage percentage

The 32 functions above are not 32 AE effects. Basic equivalents below execute, but
**no row is certified full parameter/pixel/quality parity with AE**. In particular,
the original AE effects often remove a single layer to reveal layers underneath;
here the two images are explicit. A native transparent incoming image permits
the existing Layer compositor to reveal underlying layers.

## Extended controls and shared Gaussian

On source baseline `e541ce6e09ff80b9f11c8e5e84f82376e782e5b1`, the demo
uses controlled Resource input and completed-ticket binary export. The first
checkpoint's four-interface deferral is superseded. No new owner or timeline.

`createNativeTransitions({gpu, blurMask})` binds optional shared-library services.
Direct named functions also accept that environment instead of their first GPU
argument. Existing GPU-only calls remain valid. `blurMask` must return a
caller-owned, same-size/color opaque F32 mask. It must not retire a previous
result behind the caller's back. The old unguarded Gaussian failed the unchanged
precision budget; new blurred profiles therefore fail explicitly without this
service, rather than substituting it.

The actual Resource demo uses formally installed **native-image-effects@0.3.0**
`processPa`, through `managed-gaussian.ts`. Its recipe retains/retire-last contract
requires one explicit F32 GPU copy to hand the result lifetime to the caller.
No readback or second owner. Main supplied this reviewed local package in
`c91c1f56a5ae1a7ead939318815861fab9815b00`; the project lock identifies its bytes.
The independent numeric fixture binds the now integrated, unmodified Gaussian
from `22370b15287262ead71c92601aeed77c0e62f3fc`, with its source SHA checked.
It imports the existing kernel directly; it installs no generated loader. Main owns the eventual public
pro-animation entry/version; no immutable package is replaced.

New controls (numeric animation values accept existing Signals):

- Linear: `angleDegrees`, `featherPixels`, `edgeSamples` per axis.
- Radial: `wipe` clockwise/counterclockwise/both, `angularFeatherDegrees`, sampling.
- Iris: independent `outerRadius`/`innerRadius` pixels, `points`, rotation/feather;
  either zero radius closes the aperture. Explicit radius replaces progress.
- Blinds: physical `width`, angle/feather/sampling; conflicting legacy fields fail.
- Blocks: `blockSize`, `softEdges` (4x4), spatial `featherPixels` (sigma=span/2).
- Mask wipes: stretch/center/tile `placement`, inversion. Center has transparent
  outside coverage. Glass `mapBlur` and Image `blur` are sigma in image pixels.
- Image `borderSoftness` blurs coverage. `autoSoftness` averages completion at
  16 default midpoint samples over a 180-degree LOCAL shutter. Affine FrameContext
  offset/rate are preserved. Sources and gradient remain frozen; no input Stage
  seek is performed. Animated-gradient shutter sampling remains a separate gap.
- Grid: `tiles` target area density (edge crops change actual count), `borderPixels`.
  Jaws: pixel `toothWidth`, `heightPercent` relative to width.
- Light: center, doors/round/square, rotation/reverse/source color.
- Line: pixel `thickness`, rotation, signed `slantPixels` or `overlap` 0 sequential /
  1 simultaneous. Flip reverses travel instead of reordering the strips.
- Scale: standalone `stretchOnly:true`, center and angle; no progress required.
- Cards: scale, columns-follow-rows, eight orders or a resident gradient, timing
  randomness, seed/random axis. **Still orthographic**, no empty 3D API.
- `warpTransition(a,b,options,context)` additionally derives its reactor from both
  sources. Brightness averages straight luma; brightness-difference is absolute
  luma difference; contrast-difference compares residuals from sigma-8 means;
  local-difference uses centered derivatives of the luma difference. `smoothness`
  blurs the reactor; `blendSpan` is the central temporal crossfade interval 0..1.
  Existing explicit-map brightness/contrast/local definitions stay available.

Gaussian sigma above 64 requires an undelivered shared wide kernel and fails
`E_PA_TRANSITION_BLUR_DOMAIN`, without approximation/CPU fallback. Full 3D Card
Wipe is not implemented in this parameter checkpoint. The old texture-only
owner could let a zero-alpha front card erase its rear card; the owner has since
delivered exact transparent depth-peel in `36e1b4b1dd3156e43139e51bbfa59f8ced8bec5b`,
synchronized on `d15807425bce2acc060180533ef44b074b45ef25`. This removes that
interface blocker; full camera/jitter/material adaptation continues separately.
Unknown controls still fail, instead of being accepted and silently ignored.

Full AE parameter/pixel/quality equivalence is **not certified**. Units, optical
profiles, tile calibration and proprietary reference frames still differ or are
unverified. Formal pro-animation R1/portable modes and cross-platform checks are
L3/Main work; installed Gaussian consumption is verified separately here.
