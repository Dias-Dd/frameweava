# 开发版本边界与下一阶段

当前 P4 实际执行证据见根目录 P4_REPORT.md；docs/VERIFICATION.md 保留 P4 前历史验收。协议设计不能当作后端已实现。

- 真正可执行的视觉后端是 Web。Blender、AE 和独立 GPU 后端尚未实现；StageAdapter 注册接口及 Mock 用于协议验证。
- 支持单文件原生 Stage：`factory` 必须是项目入口的具名导出，构建时解析为模块路径与导出名；其他模块可通过入口重导出，或显式使用 `entry`/`exportName`。这不会序列化函数或构建进程中的闭包状态；同模块私有辅助函数与常量按标准 JS 模块语义保留。
- 同一文件使用一种标准 JSX Runtime。自定义视频 TSX 中可用 `React.createElement` 编写原生 React UI；使用 React JSX pragma 的文件可用 `Composition(...)`、`Stage(...)` 等函数创建视频结构。原生 React JSX 仍可放在独立文件中；不支持在同文件按标签或函数隐式切换 Runtime。
- 单文件模块会分别在 Node 构建环境与各浏览器 Stage 中加载；需要 DOM/WebGL 的初始化必须放在原生工厂内。模块导入及顶层副作用需要兼容这些环境，Node 专用构建逻辑可与浏览器原生入口分文件。模块状态不会随源文件合并而在 Stage 间共享；构建时生成的数据应显式放入 `props` 或输入端口。
- 旧 Layer 效果保留 Canvas Filter 执行路径；P4 PluginStage 另行支持六类插件及组合。Web 插件可自行使用原生 JS/Three/Pixi/Shader，但没有外部专业引擎 Adapter、插件市场或远程自动安装。
- 原生代码必须按传入的绝对时间设置状态，避免自己启动动画循环。逻辑时钟和逐帧随机种子帮助复现；它们不能证明任意第三方代码都具备随机访问能力。
- 有状态模拟可在 Stage 内使用 FixedStepRunner，固定步长并从检查点回放。其状态必须可克隆，积分函数必须确定；引擎不会自动理解或修复任意物理引擎的隐藏状态。
- 相同依赖、浏览器、字体、操作系统和渲染配置下进行重复性验证。没有承诺跨 GPU、浏览器版本、平台的逐像素相同结果；渲染器指纹进入缓存键。
- 缓存为有界的进程内 Stage 输出缓存；全局构建指纹变化时，未修改的 Stage 也不能跨 Renderer 复用（审计 A004，性能改进项）。跨 Stage 传输 PNG 的开销较大，未来可增加持久化依赖缓存和共享传输。
- 输入端口有构建及运行时契约；具体 TS 泛型可推断，动态输入需显式 inputTypes。json 只验证传输格式，不验证业务对象内部完整结构。不会给任意第三方库自动生成运行时验证器。
- 声明式 DOM 每帧重建子树，消除已复现的变换绘制历史差异（A002）；原生 Stage 仍由作者管理状态。逐像素回归覆盖指定审计用例和当前固定环境，不能证明所有原生程序、平台及浏览器组合都一致。
- 父子 Layer 的变换和透明度相乘。当前未使用独立离屏缓冲实现整组透明度，重叠子图层的组透明度可能与专业合成软件不同；效果应添加在承载 Surface 的图层上，父组效果不会自动作用到所有子图层。
- PNG/RGBA、H.264 MP4 与 P4 Stage 内上游生成器的时间采样运动模糊已实现。音频、完整视频素材解码/剪辑、HDR、完整色彩管理、跨 Stage 运动采样、编辑器 GUI 尚未实现。Resource 能提供本地媒体文件，但不是完整 NLE 媒体系统。
- P4 当前输出图像/标量/JSON，Stage 边界仍传 PNG/JSON。4 Mi 像素画布、64 Mi 像素快照池、16 步管线、512 次逐帧更新与超时是宿主预算，不是恶意代码的 OS 配额。只支持受信任的本地插件。
- 黑屏/透明帧为启发式告警；文字溢出与越界仅覆盖可测量的声明式 DOM 节点和原生 Stage 主动标注的元素，不能检查任意 Canvas/3D 场景内部文字或判断审美质量。
- FFmpeg 为独立 GPL v3 可执行工具，原生字体/图像库有各自许可证；核心 Apache-2.0 不替代这些许可证。
- 沙箱不适合不受信任的远程工程。当前用户级构建进程仍能访问宿主文件系统，详见 SECURITY.md。

下一阶段优先顺序：OS 级安全执行；持久化依赖感知缓存与增量渲染；媒体/音频与色彩管理；可视化时间轴和差异检查；然后接入真实 Blender/AE 适配器及受控 Shader/组件插件。每项都应保留 Stage 显式端口和统一时间契约。
